# Synthetic Data Factory Module

This module is responsible for deterministic generation of the interconnected healthcare and denial universe.

## Target Generation Scope (Phase 3 - Phase 5)
- Provider organizations, facilities, practitioners
- Patients, coverage periods, insurance policies
- Clinical timelines: encounters, conditions, procedures, observations, notes
- FHIR R4-shaped resource mappings
- Claims, claim lines, remittances (835), denial reason codes (CARC/RARC)
- Ground-truth evidence links and synthetic appeal outcomes

**Status**: Foundation prepared. Generation begins in Phase 3 after database schema design.
